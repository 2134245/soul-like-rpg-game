# Soul Rift: Boss Breaker

這是一款可直接在瀏覽器中開啟玩的動作 RPG 原型，風格偏向「靈魂系」Boss 挑戰：

- 近戰連段與重擊
- 格擋後觸發慢動作
- 每個 Boss 都有不同攻擊節奏
- 打贏 Boss 後會進入升級選項
- 總共四位 Boss，最後一位為終章

## 遊玩方式

1. 打開 `index.html` 直接瀏覽器執行
2. 或在專案目錄中啟動本機伺服器：

```bash
python -m http.server 8000
```

3. 然後訪問：

```text
http://localhost:8000
```

## 控制

- `W A S D`：移動
- `J`：攻擊
- `K`：重擊
- `L`：格擋
- `Shift`：閃避

## 遊戲流程

- 角色在戰場中與 Boss 近距離交戰
- 格擋成功會讓時間變慢一小段，讓你能反擊
- 每擊敗一名 Boss，會出現三個升級選項
- 選擇後繼續下一位 Boss
- 打完全部 Boss，遊戲勝利

## 檔案結構

- `index.html`：遊戲主頁面
- `style.css`：UI 與畫面風格
- `game.js`：遊戲邏輯、Boss AI、升級系統
